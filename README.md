# iphone-forensics tool by pental

## Install
Requires [Python 3.4](https://www.python.org/) or higher.

Ideal dependencies:
```bash
pip install pyqt
```
Or
```bash
pip install - r requirements.txt
```

## Run
```py
python run.py
```
